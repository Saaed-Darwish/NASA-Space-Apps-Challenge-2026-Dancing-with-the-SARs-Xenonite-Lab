# Satellite Data Pipeline — Dancing with the SARs

This directory documents the satellite data acquisition, processing, testing, and validation conducted for the NASA Space Apps Challenge 2026.

## Research Scope

Four geographic study regions:
- Brazil
- Vietnam
- Italy
- United Kingdom (London)

## Documentation

This directory will contain:
- Google Earth Engine scripts used to retrieve satellite observations
- Data sources and supporting scientific resources
- Testing procedures and console validation checks
- Methodological decisions and alternative approaches evaluated
- Data quality assessments and limitations
- Final processed datasets and reproducibility instructions

## Objective

To provide a transparent and reproducible record of the satellite data pipeline, including the methodological decisions and trade-offs made under hackathon time constraints.
